# Один запрос списка скопирован по страницам

`Home`, `MyAds` и `Moderate` повторяют один эффект. Страница вызывает `listAds`, кладёт ответ в свой `useState` и сама показывает загрузку или ошибку. Контексты объявлений и справочников запрос только прокидывают и ответ не запоминают.

Избранное, чаты и уведомления лежат в контексте на всё приложение. Фильтр «Избранное» на главной режет массив, который страница скачала отдельно.

# Карточка и форма держат несколько задач сразу

`AdMain` в одном компоненте содержит галерею, действия владельца, модерацию и окно телефона. `CreateAd` содержит форму, загрузку и превью фото.

# Проверка входа и роли размазана по экранам

Роль админа отдельно проверяют шапка, карточка объявления и страница модерации, каждый раз через `keycloak.realmAccess`. Общей защиты маршрута нет. Модерация уводит не-админа на главную. Остальные страницы сами решают, что показать гостю.

Удаление объявления спрашивает через `confirm`.

В форме создания пустые категория и город становятся первыми пунктами справочника, если пользователь их не трогал.

# Идентификатор чата собирается на клиенте

Карточка объявления сортирует два логина и склеивает их через `_` в строку `{id объявления}_{логин}_{логин}`. Мессенджер режет её через `split('_')` и ждёт три части.

Логин с `_` ломает переход в чат и запасной разбор, когда диалога ещё нет в списке. Разный порядок логинов даёт два чата. Сервер принимает уже готовую строку и пару сам не создаёт.

# Открытый диалог не обновляется

Сообщения запрашиваются один раз при смене `chatId`. Новое сообщение собеседника в уже открытом окне не появляется. Список чатов обновляется после своей отправки. Уведомления опрашиваются примерно раз в 20 секунд и ленту сообщений не перечитывают.

# Токен подставляется как есть

Каждый контекст сам кладёт в заголовок текущий `keycloak.token`. Перед запросом токен не обновляется. Обновление висит на `onTokenExpired`. Если оно не успело, запрос уходит со старым токеном. Если обновление не удалось, экран на вход не уводит.

Дальше запросы получают 401. Ошибка остаётся в консоли. Экран по-прежнему считает пользователя вошедшим.

# Каталог рассчитан на полный ответ

Главная вызывает `GET /ads` без страницы и кладёт ответ в один массив. Фильтр «Избранное» оставляет из этого массива id, которые уже есть в контексте избранного. Объявление из избранного, не попавшее в текущий ответ API, на экране не появляется.
